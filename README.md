
# 💻 Algoritmos e Lógica de Programação

Repositório dedicado aos meus estudos de **Algoritmos e Lógica de Programação**, reunindo exercícios e códigos desenvolvidos em diferentes linguagens.

O objetivo é praticar os conceitos fundamentais da programação, aprimorar o raciocínio lógico e registrar minha evolução ao longo dos estudos.

## 📚 Conteúdos

- **Estrutura Sequencial:** variáveis, operadores e entrada e saída de dados.
- **Estrutura Condicional:** estruturas de decisão (`if`, `else`).
- **Estrutura Repetitiva:** laços de repetição (`for`, `while`).
- **Vetores e Matrizes:** armazenamento e manipulação de dados.
- **Funções e Procedimentos:** organização e reutilização de código.

## 🚀 Linguagens de Programação

- **Portugol (Visualg):** exercícios de lógica.

- **C++:** planejado.
- **C#:** planejado.

## 📂 Organização

Os exercícios estão organizados em pastas por assunto e linguagem, facilitando a consulta e o acompanhamento dos conteúdos estudados.

O repositório será atualizado conforme avanço nos estudos e desenvolvo novos exercícios em diferentes linguagens.

## 🎯 Objetivos

- Aprimorar minha lógica de programação.
- Praticar a resolução de problemas.
- Aprender novas linguagens de programação.
- Desenvolver códigos cada vez mais organizados.
- Registrar minha evolução como desenvolvedor.
